🏗️ Five-Tier System Architecture

1️⃣ Sensor Layer (Physical)

50+ heterogeneous sensors: temperature, humidity, light, motion, CO2, cameras, soil moisture across 14 rooms. Power consumption: 0.5W per sensor.

2️⃣ Edge Preprocessing Layer

Local filtering, outlier detection (z-score ≥ 3.0), exponential moving average smoothing, quality assurance - reduces bandwidth by 18%

3️⃣ Gateway Intelligence Layer

Protocol translation (JSON ↔ XML ↔ SOAP), energy-aware scheduling, priority queuing (high/normal/low), data buffering (1000 messages)

4️⃣ Cloud Analytics Layer

MongoDB data warehousing, AI-powered predictions, real-time anomaly detection, ML model training, statistical analysis, visualization

5️⃣ Actuator Control Layer

ML-driven prescriptive control (Random Forest), safety validation, automated HVAC/lighting/irrigation with 30+ actuators
