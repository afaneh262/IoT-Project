🏗️ System Architecture

1️⃣ Sensor Layer

50+ heterogeneous sensors collect environmental, occupancy, energy, and agricultural data across all rooms

2️⃣ Edge Preprocessing

Local filtering, outlier detection (z-score), data smoothing (EMA), and quality assurance - 18% noise reduction

3️⃣ Gateway Intelligence

Protocol translation (JSON/XML/SOAP), energy-aware scheduling, priority queuing, and data buffering (1000 messages)

4️⃣ Cloud Analytics

MongoDB storage, AI predictions, anomaly detection, ML model training, and real-time visualization

5️⃣ Actuator Control

ML-driven prescriptive control (Random Forest), safety validation, automated HVAC/lighting/irrigation, and feedback loop
